## Vocabulary

| Class                           | Meaning                                                                                                             | What 25B does with it                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **LIVE-INTENDED (LI)**          | A value the roadmap expects to be real on the primary machine, currently static, fixture, mock or unreachable       | Realize, one at a time, each with a kill-drill |
| **DELIBERATELY-SYNTHETIC (DS)** | A fail-closed boundary or a by-design demo shape: gated providers, blocked CAI, demo director, labelled sample data | Keep; label; never dress as live               |

Risk ranks for LI items: **R1 read-only** (a wrong value misinforms) →
**R2 state-bearing** (a wrong value persists or routes) → **R3
Gate-adjacent** (the value sits on the approval path; touching it means
`tool-approvals.ts`, `tool-continuation.ts`, `tools/runtime.ts` or
`mcp-gateway/**` — deferred to its own brief per the opener rule).
