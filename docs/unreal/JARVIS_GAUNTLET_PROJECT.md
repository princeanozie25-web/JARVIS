## Opening on Another Windows Machine

1. Clone the JARVIS repository.
2. Check out `unreal-gauntlet-lab`.
3. Install Git LFS.
4. Install Epic Games Launcher from the official Epic Games website.
5. Install the matching Unreal Engine version, currently Unreal Engine 5.7.
6. Use the repository-imported project path:

```text
<repo>\unreal\JarvisGauntlet
```

7. Run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/unreal/verify-unreal.ps1
```

8. Open the `.uproject` with Unreal Editor, or run the build command printed by the script.

## Opening on a MacBook Later
