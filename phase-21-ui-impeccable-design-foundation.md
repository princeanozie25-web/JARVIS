# ============================================================

# PHASE 21 UI

# IMPECCABLE DESIGN FOUNDATION AUDIT

# ============================================================

Source:

- https://github.com/pbakaus/impeccable

Goal:

Install/use Impeccable to establish the JARVIS UI design foundation.

This is NOT a redesign pass.

# SINGLE AGENT ONLY

Do not spawn subagents.

# HARD CONSTRAINTS

DO NOT:

- redesign components
- rewrite UI screens
- create new UI routes
- change styling broadly
- remove functionality
- modify runtime logic

Audit and design foundation only.

# REQUIRED WORK

1. Install/use Impeccable safely.

2. Run the equivalent of:

- init
- document
- critique/audit

3. Generate or update:

- PRODUCT.md
- DESIGN.md

4. Audit current UI for:

- AI slop patterns
- generic SaaS/chatbot tells
- purple/blue gradient overuse
- nested cards/card soup
- typography weakness
- spacing/hierarchy weakness
- command center inconsistency
- accessibility risks
- motion/design-system gaps

5. Define JARVIS design direction:

- cinematic command center
- orb-first
- operational HUD
- information-dense but readable
- not generic AI SaaS

6. Produce a future UI polish roadmap.

# REQUIRED COMMANDS

npm test
npx tsc --noEmit
git diff --check

1. Effort level
2. Files changed

4. PRODUCT.md summary
5. DESIGN.md summary
6. UI audit findings
7. AI slop risks found
8. Proposed JARVIS design language
9. Future UI polish roadmap
10. Commands executed
11. Suggested commit message
